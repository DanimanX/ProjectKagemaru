## ProjectKagemaru v1.1.0-arm64 — Standalone Vulkan (`SDL_GPU` SPIR-V) Runtime

This release adds a second standalone, ROM-free AArch64 binary (`vf1-vulkan.aarch64`, packaged as `ProjectKagemaru-Vulkan-aarch64.zip`) alongside the existing OpenGL ES 2.0 PortMaster build (`ProjectKagemaru-PortMaster-aarch64.zip`).

### What's new

- **Standalone AArch64 Vulkan runtime (`vf1-vulkan.aarch64`):** built with static **SDL3 (`SDL_GPU` Vulkan + SPIR-V compute shaders)**, Dear ImGui `SDL_GPU3`, SLJIT ARM64, Musashi 68000 + Z80 sound, and static `zlib` / `libc++` (`max GLIBC_2.27`, zero `libstdc++.so` / `libSDL3.so` / `libz.so` dependency). `libvulkan.so.1`, Wayland, X11, and PipeWire / PulseAudio / ALSA are loaded dynamically at runtime via `dlopen`.
- **Model 1 3D on the GPU:** delegates polygon rasterization to SPIR-V compute shaders in `platform/arm64/gpu_vulkan.cpp`, compositing System 24 2D layers directly on the Vulkan swapchain.
- **Shared ARM64 core:** the same SLJIT ARM64 V60 recompilation, pre-decoded TGP, and Core 2 MultiPCM sound worker as the OpenGL ES 2.0 build, so gameplay behaviour is identical between the two packages.

### Which package should I use?

- **Anbernic RG34XX / Allwinner H700 (Mali-G31 MP2):** use `ProjectKagemaru-PortMaster-aarch64.zip`. That GPU has no Vulkan driver, and this release does not change that build.
- **ARM64 Linux devices with a working Vulkan driver** (Mesa, proprietary drivers): `ProjectKagemaru-Vulkan-aarch64.zip` is the standalone runtime.

### Unchanged

The OpenGL ES 2.0 PortMaster build (`vf1.aarch64` / `ProjectKagemaru-PortMaster-aarch64.zip`) for the RG34XX remains the recommended package for the H700. Zero ROMs and zero game code are included in either archive.
